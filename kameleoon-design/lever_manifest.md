# Lupine Lever Framework: Comprehensive Manifest


| Level 1: Master Lever | Level 2: Lever | Level 3: Example Sub-Levers | Description & Key Questions |
| :--- | :--- | :--- | :--- |
| **Comprehension** | Education | Industry Clarity | Do users understand the general type of product/service? |
| | Product Understanding | Details, Features | Do users understand specific product features & benefits? |
| | Transactional Understanding | Shipping, Terms | Do users understand the checkout process and terms? |
| | Value Proposition | USP, Messaging | Does the hero messaging clearly state what is being offered? |
| **Motivation** | Value Statement | USP Clarity | Do product descriptions inspire and excite the user? |
| | Motivational Depiction | Hero Visuals | Does product imagery evoke anticipation and emotion? |
| | Social Proof | Reviews, Testimonials | Do expert/peer reviews build the desire to convert? |
| | Urgency | Scarcity, Time-limit | Is it important to convert *now* or in this session? |
| | Obligation | Reciprocity | Does the user feel a sense of duty or obligation to convert? |
| | Sociability | Community | Does conversion offer access to a community? |
| | Product Range | Variety | Is there a sufficient variety of options/access? |
| | Delivery | Access Methods | Is the method of receiving the product compelling? |
| | Gamification | Fun, Addictive | Is the experience fun or engaging to use? |
| | Stimulation | Mental Engagement | Is the user mentally stimulated by the content? |
| | Humanisation | Personalization | Does the brand feel human or personally connected? |
| | Control | Agency | Does the user feel in control of their choices? |
| | Preview Content | Try-before-you-buy | Can the user experience qualities before purchasing? |
| **Trust** | Legitimacy | Branding, UI quality | Is this a real company or a potential scam? UI quality includes image resolution and professional appearance. |
| | Credibility | Accreditations | Do I believe the claims about product quality? |
| | Security | Encryption, Data Privacy | Is there visible protection for sensitive information? |
| **Cost** | Financial Cost | Pricing, Discounts | Is the monetary price clear and acceptable? |
| | Soft Cost | Time, Effort, Friction | Is the required commit of time and effort worth it? |
| | Commitment | Flexibility | How flexible are terms for avoiding or adjusting costs? |
| | Fit Uncertainty | Sizing, Compatibility | Is the user worried the product won't fit or work for them? |
| **Usability** | User Flow | Navigation, Progress | Does the user know where they are and their next step? |
| | Effort | Fatigue, Minimalism | Is the interaction require high cognitive or physical effort? |
| | Choice | Findability | Is the presentation of options effective? |
| | Attention | Visual Hierarchy | Is attention allocated to the most useful elements? |
| | Persistence | Feedback, Validation | Is on-site progress acknowledged clearly? |
