# Lupine Lever Framework Definitions


| Master Lever | Primary Question | Mechanism & Description | Specific (Child) Levers |
| :--- | :--- | :--- | :--- |
| **Comprehension** | Can the user understand what is being offered? | Addresses clarity of messaging, product information, and transactional details. When users struggle to comprehend the offering or how transactions work, conversion friction increases regardless of other factors. | Education, Product Understanding, Transactional Understanding |
| **Motivation** | Does the user want to take action? | Encompasses value perception, urgency, social proof, and incentive structures. Even when users understand an offering, insufficient motivation prevents action. | Value Statement, Obligation, Sociability, Urgency, Product Range, Delivery, Gamification, Preview Content, Motivational Depiction, Stimulation, Humanisation, Control |
| **Trust** | Does the user believe and accept the offering? | Covers legitimacy signals, credibility indicators, and security assurances. Users may understand and want something but hesitate due to concerns about authenticity or safety. | Legitimacy, Credibility, Security |
| **Cost** | Can the user afford it (financially, cognitively, temporally)? | Addresses pricing clarity, perceived effort, and commitment concerns. High cost (financial, cognitive, or temporal) creates barriers even when other factors align. | Financial Cost, Soft Cost, Commitment |
| **Usability** | Can the user interact with the interface easily? | Covers navigation, findability, visual attention, and interaction friction. Poor usability prevents users from completing intended actions. | User Flow, Effort, Choice, Attention, Persistence |
