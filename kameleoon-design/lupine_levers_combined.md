# Lupine Lever Framework (Combined)

### 1. Master Levers & Descriptions

| Master Lever | Description | Specific (Child) Levers |
| :--- | :--- | :--- |
| **Comprehension** | Can the user understand what is being offered? Addresses clarity of messaging, product information, and transactional details. | Education, Product Understanding, Transactional Understanding |
| **Motivation** | Does the user want to take action? Encompasses value perception, urgency, social proof, and incentive structures. | Value Statement, Obligation, Sociability, Urgency, Product Range, Delivery, Gamification, Preview Content, Motivational Depiction, Stimulation, Humanisation, Control |
| **Trust** | Does the user believe and accept the offering? Covers legitimacy signals, credibility indicators, and security assurances. | Legitimacy, Credibility, Security |
| **Cost** | Can the user afford it (financially, cognitively, temporally)? Addresses pricing clarity, perceived effort, and commitment concerns. | Financial Cost, Soft Cost, Commitment |
| **Usability** | Can the user interact with the interface easily? Covers navigation, findability, visual attention, and interaction friction. | User Flow, Effort, Choice, Attention, Persistence |

---

### 2. Detailed Lever Hierarchy (Manifest)

| Level 1: Master Lever | Level 2: Lever | Description / Key Focus |
| :--- | :--- | :--- |
| **Comprehension** | Education | Do users understand the general type of product/service? |
| | Product Understanding | Do users understand specific product features & benefits? |
| | Transactional Understanding | Do users understand the checkout process and terms? |
| **Motivation** | Value Statement | Do product descriptions inspire and excite the user? |
| | Motivational Depiction | Does product imagery evoke anticipation and emotion? |
| | Social Proof | Do expert/peer reviews build the desire to convert? |
| | Urgency | Is it important to convert *now* or in this session? |
| | Obligation | Does the user feel a sense of duty or obligation to convert? |
| | Sociability | Does conversion offer access to a community? |
| | Product Range | Is there a sufficient variety of options/access? |
| | Delivery | Is the method of receiving the product compelling? |
| | Gamification | Is the experience fun or engaging to use? |
| | Stimulation | Is the user mentally stimulated by the content? |
| | Humanisation | Does the brand feel human or personally connected? |
| | Control | Does the user feel in control of their choices? |
| | Preview Content | Can the user experience qualities before purchasing? |
| **Trust** | Legitimacy | Is this a real company or a potential scam? UI quality (cues like professional appearance) signals legitimacy. |
| | Credibility | Do I believe the claims about product quality? |
| | Security | Is there visible protection for sensitive information? |
| **Cost** | Financial Cost | Is the monetary price clear and acceptable? |
| | Soft Cost | Is the required commit of time and effort worth it? |
| | Commitment | How flexible are terms for avoiding or adjusting costs? |
| **Usability** | User Flow | Does the user know where they are and their next step? |
| | Effort | Is the interaction require high cognitive or physical effort? |
| | Choice | Is the presentation of options effective? |
| | Attention | Is attention allocated to the most useful elements? |
| | Persistence | Is on-site progress acknowledged clearly? |
